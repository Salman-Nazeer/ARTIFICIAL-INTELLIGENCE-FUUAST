# Travel Agent System

A simple Python-based flight booking console program that lets a user search for available flights between a departure city and destination city, view flight options, and book a flight by selecting a valid flight ID.

## Project Overview
This project simulates a basic travel booking system for a small airline database. It allows the user to:

- enter a departure city
- enter a destination city
- view all matching flights
- choose a flight ID to book
- receive success or error feedback depending on the selected ID

## Features
- City-based flight search
- Flight price display
- Valid ID validation before booking
- User-friendly console messages
- Small built-in flight database

## File Structure
- `m_salmannazeer_lab1.py` - Main Python script containing the travel agent logic
- `README.md` - Project documentation

## How to Run
1. Open a terminal in the project folder.
2. Run:

```bash
python m_salmannazeer_lab1.py
```

3. Follow the prompts to enter:
   - departure city
   - destination city
   - flight ID to book

## Example
Example input:

```text
Enter departure city: Karachi
Enter destination city: Lahore
```

The program will display all matching flights and ask for the flight ID to book.
